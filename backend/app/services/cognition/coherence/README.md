# Coherence Engine

## Purpose

The Coherence Engine protects alignment between SentinelAI's identity and knowledge.

It answers one question:

Does this reasoning remain consistent with the Constitution?

## Responsibility

The Coherence Engine evaluates whether a recommendation, answer, or workflow conflicts with SentinelAI's principles.

## Design Principle

Knowledge expands capability.

Identity protects direction.

Coherence keeps them aligned.
