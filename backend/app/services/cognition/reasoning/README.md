# Reasoning Domain

## Purpose

The Reasoning domain coordinates SentinelAI's thinking workflow.

It does not own identity.

It does not own knowledge.

It coordinates the process that turns intent, identity, and knowledge into a response.

## Responsibility

The Reasoning domain will coordinate:

- Reasoning requests
- Identity consultation
- Knowledge retrieval
- Coherence checks
- Prompt assembly
- Model interaction
- Reflection
- Response formatting

## Design Principle

The orchestrator owns workflow.

Specialized services own execution.
