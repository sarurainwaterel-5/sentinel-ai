# Identity Layer

## Purpose

The Identity Layer defines who SentinelAI is.

It contains the platform's Constitution: vision, manifesto, principles, Builder's Oath, language, cognitive design, and architecture decisions.

## Responsibility

Identity provides guidance before reasoning happens.

It helps SentinelAI answer:

- Who am I?
- What principles guide this decision?
- What language should I use?
- Does this align with the Constitution?

## Design Principle

Identity changes intentionally.

Knowledge grows continuously.

Normal uploaded knowledge should never override SentinelAI's identity.
