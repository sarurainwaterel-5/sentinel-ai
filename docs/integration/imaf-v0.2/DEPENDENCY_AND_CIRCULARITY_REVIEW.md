## Explicit cycle analysis

**CY01 participation ← narrative ← transition ← participation.** Reject using an
already assumed narrative to prove participation. Require source-linked observations
and alternatives available before that inference. A later coherent narrative may
corroborate a later assessment only. D4's exact independence/sufficiency remains null.

**CY02 rejection confirmation ← accepted transition ← confirmed rejection.** D2's
structural route must not mean the identical accepted-transition conclusion when that
transition requires the same confirmed rejection. Owner options C02 are distinct raw
structural support or sequential assessments with explicit preliminary inputs. If
neither is selected, the route is unresolved; do not execute topological evaluation
by arbitrarily declaring one true. Whether provisional or confirmed response is
sufficient input to accepted transition remains an owner question.

**CY03 accepted transition ← completed Price Delivery ← accepted transition.** D5
requires persistence and price-delivery confirmation. Proposed separation: raw delivery
facts available before transition vs completed later Price Delivery synthesis. If owner
requires the completed later stage itself as prerequisite, a different noncircular
operational interpretation must be approved. Record persistence and delivery lineage
separately; chosen trade direction has no evidential force.

**CY04 narrative ← FVG ← direction selected from narrative.** Geometry can be computed
without declaring the narrative true. Contextual eligibility depends on earlier
auction evidence; an FVG label is neither independent participation nor narrative
sufficiency. Disclose overlapping input bars and shared hypotheses.

**CY05 bias ← favorable target ← bias.** Freeze initial context/objective and the
candidate set at the recorded cutoff. Later ranking may use new context, but appends
a new assessment and cannot justify the earlier directional hypothesis. Keep original
ranking rationale, excluded alternatives and subsequent acquired flags distinct.

**CY06 early decision ← later outcome.** For each evidence reference, retain event,
close and actual availability times, input revision and derivation dependencies.
Eligible source facts must be closed and available by decision cutoff. A derived
result cannot be available before any input it uses. Late arrival delays confirmation;
revised history/outcomes cannot repair an earlier missing prerequisite.
