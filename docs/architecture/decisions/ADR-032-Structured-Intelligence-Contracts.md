# ADR-032 — Structured Intelligence Contracts

**Status:** Accepted

**Date:** Sprint 13.2

---

# Context

SentinelAI originally returned large blocks of formatted text generated by the language model.

Although readable, this approach tightly coupled the backend reasoning pipeline with frontend presentation.

Frontend improvements required parsing natural language output rather than consuming structured information.

This created unnecessary complexity and limited future capabilities.

---

# Decision

SentinelAI now returns a structured intelligence contract rather than a formatted response.

The Recall API exposes a stable JSON object containing independently addressable fields.

Example:

```json
{
  "answer": "...",
  "confidence": {
    "score": 0.82,
    "level": "high",
    "basis": "..."
  },
  "recommended_next_step": "...",
  "suggested_follow_up": "...",
  "related_knowledge": [],
  "sources": []
}
```

ReasoningService is responsible for intelligence generation.

Frontend components are responsible for presentation.

Each section of the Recall experience now renders independently without parsing formatted text.

---

# Consequences

## Positive

- Stable API contract
- Clear separation of reasoning and presentation
- Easier frontend evolution
- Easier testing
- Enables confidence visualization
- Enables related knowledge visualization
- Enables future domain-aware reasoning
- Enables future autonomous reasoning workflows

## Tradeoffs

- Slightly larger response payload
- More backend responsibility for response structure

# Future Impact

This decision establishes the contract used by future Sentinel capabilities including:

- Domain-Aware Recall
- Cross-Domain Reasoning
- Investigation Workspaces
- Cognitive Retrieval Engine
- Autonomous Intelligence Reports

---

# Result

Sprint 13.2 transitions SentinelAI from returning formatted language to returning structured intelligence.

This becomes the permanent Recall response contract moving forward.
