# ADR-007: Sentinel Language

## Status

Accepted

## Context

SentinelAI should not feel like a generic file manager or chatbot. The interface should communicate what the system is helping the user do, not expose technical implementation details.

## Decision

SentinelAI will use human-centered language that reflects knowledge, memory, reasoning, and intelligence.

Examples:

- Upload becomes Remember Knowledge
- Search becomes Recall
- Dashboard becomes Bridge
- Delete becomes Forget
- Archive becomes Hibernate
- Restore becomes Awaken
- Loading becomes Thinking

## Consequences

- The product experience feels more natural and intentional.
- UI copy must follow the Language Guide.
- Technical names may remain precise internally, but user-facing language should reflect SentinelAI’s vocabulary.
