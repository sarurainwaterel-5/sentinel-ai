# SentinelAI Architecture

> "Architecture is preserved reasoning."

The SentinelAI architecture is intentionally layered. Every significant
engineering decision is documented as an Architecture Decision Record (ADR).

These records explain not only **how** SentinelAI is built, but **why** it is
built that way.

# Design Philosophy

SentinelAI follows several core principles:

- Identity before intelligence
- Constitution before reasoning
- Knowledge before answers
- Operational awareness before operational intelligence
- Human experience before implementation

---

Architecture evolves through deliberate decisions, not accidental complexity.
