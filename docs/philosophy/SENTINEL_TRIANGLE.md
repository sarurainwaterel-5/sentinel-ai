# Domain Principle

Operational Domains specialize SentinelAI's operation while preserving a
single validated constitutional identity.

A domain defines the operational context in which SentinelAI applies its
knowledge, capabilities, language, workflows, policies, boundaries, and
evidence.

Domains do not create new identities.

Domains do not alter SentinelAI's constitutional principles.

Instead, domains assemble validated architectural components into a
discipline-specific operating context while preserving one coherent
SentinelAI.

Identity is permanent.

Operational context is selected.

**One Identity. Many Domains. One SentinelAI.**
