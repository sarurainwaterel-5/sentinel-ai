# Sentinel workspace usability

The local interface groups daily work by task while retaining the Sentinel distinction between evidence, confidence, constitutional admissibility, and human authority.

- Intelligence has Connections, Reflection, and Planning tabs. Switching tools preserves drafts and results until leaving the workspace. Arrow keys, Home, and End navigate the tab list.
- Connections supports search, relationship filtering, clickable endpoints, and a local directional relationship map. These are observed structural relationships, not inferred semantic claims. Unresolved references appear only when present.
- Reflection offers a teaching action when the current domain has no Learning Events. It never manufactures history to enable the operation.
- Governance has Documents, Verify, and Principles tabs. Documents default to active records and support archived/all filters, newest/name sorting, upload dates, metadata inspection, and reversible lifecycle feedback with Undo. Archived synthetic verification documents remain available in the Archived view.
- Workspace purpose, archive behavior, architectural acceptance details, and evaluation limitations are expandable. Human authority and unverified constitutional evaluation remain explicit.
- Header readiness expands into service observations, provider configuration, refresh, and Systems navigation. Storage readiness is not a semantic accuracy claim.
- Navigation groups destinations by purpose and labels collapse/expand accurately. Muted text has stronger contrast, and connection details use page scrolling rather than a second nested scroll area.

No database migration, authentication change, provider call policy change, or cognitive acceptance change is part of this UI update.
