# Sentinel Engineering Foundations

This directory contains Sentinel's Foundational Documents (FD).

These documents define the enduring engineering philosophy, architectural
principles, and construction methodology that govern the evolution of
Sentinel.

Unlike sprint documentation or Architecture Decision Records (ADRs),
Foundational Documents are intended to remain stable over time. They
describe *how Sentinel is engineered*, not how a particular feature was
implemented.

Every future architectural decision should be evaluated against these
foundational principles.
