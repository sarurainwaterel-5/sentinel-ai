# The SentinelAI Canon

This repository contains more than documentation.

It contains the permanent knowledge that defines SentinelAI.

These writings preserve the philosophy, identity, architecture,
engineering practices, and cognitive model that shape the platform.

Every major engineering decision is reflected here.

The Canon exists to ensure SentinelAI remains understandable,
coherent, and aligned across time.

## Architecture

Architecture Decision Records (ADRs), diagrams, and system evolution.

## Design

Design system, language guide, cognitive UX, and component library.

## Engineering

Development workflow, coding standards, Git, Linux, and engineering playbooks.

## Philosophy

Vision, Manifesto, Principles, Builder's Oath, and SentinelAI's governing philosophy.

## Sprints

Historical record of SentinelAI's evolution.

## Documentation Philosophy

Documentation is part of the product.

Every document should help future builders understand not only how SentinelAI works, but why it was designed that way.
